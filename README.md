# lhds-2 · La Hermana de Shakespeare (versión sencilla)

Lo mismo que [LHDS](https://github.com/uiuaaxyz/LHDS), pero escrito solo con HTML, CSS y JavaScript básicos,
usando los ejemplos de [W3Schools](https://www.w3schools.com/howto/). No hay frameworks ni datos en JavaScript:
todo el contenido está escrito directo en el HTML, así que se edita como cualquier página de W3Schools.

Para verlo, abre `index.html` en el navegador.

## Archivos
- `index.html`: página principal (cartelera, convocatorias, revista, muro de recuerdos, sobre nosotras, prensa)
- `archivo.html`: archivo histórico por años (2018–2024)
- `aviso-legal.html`: aviso de privacidad (texto de ejemplo)
- `css/estilos.css`: estilos. Cada bloque dice de qué ejemplo de W3Schools viene
- `js/script.js`: funciones de W3Schools: menú responsivo, filtro, pestañas, modal, imágenes en grande y botón flotante
- `img/`: logos oficiales y fotos del archivo
- `docs/`: bases de convocatorias (de ejemplo) y kit de prensa
